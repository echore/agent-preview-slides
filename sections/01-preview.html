Concept A · What is an agent

An agent is an AI that can take actions on its own to finish a task.

Goal

You describe the goal and what “done” looks like.

Tools

It can open files, search, write, and run things.

Loop

It works step by step, checking progress as it goes.

Source: Anthropic, “Building Effective Agents”

Module 1 · Preview

Concept B · How it works

It works in a loop.

Reason

Given what I know so far, what is the best next step?

Act

Do that one step, usually with a tool.

Observe

What came back? Did it work? Anything unexpected?

It stops when the task is done, blocked, or needs your input.

Source: Yao et al., “ReAct: Synergizing Reasoning and Acting in Language Models” (2022)

Concept C · What’s inside

Think of an agent as three parts.

Agent loop context · results · repeat or stop
Model chooses the next step
↔
Tools get information and act
Model

Understands the situation and chooses the next step.

Tools

Let it get information and take action.

Agent loop

Keeps context, returns results, and repeats or stops.

The model decides. Tools act. The loop connects them.
