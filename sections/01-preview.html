Concept A · What is an agent

An agent is an AI that can take actions on its own to finish a task.

Goal

You describe what “done” looks like. Not the steps.

Tools

It can open files, search, write, and run things.

Loop

It keeps working, step by step, until the goal is met.

Source: Anthropic, “Building Effective Agents”

Module 1 · Preview

Concept B · How it works

It works in a loop.

Reason

Given what I know so far, what is the best next step?

Act

Do that one step, usually with a tool.

Observe

What came back? Did it work? Anything unexpected?

It stops when the goal is met, or when it needs to ask you something.

Source: Yao et al., “ReAct: Synergizing Reasoning and Acting in Language Models” (2022)

Concept C · What’s inside

An agent has two parts.

Model

The part that thinks. It reads text and writes text. That is all it can do.

Harness

The software around the model. It gives the model its tools, carries out what the model decides, brings the results back, and keeps track of the whole conversation.

The model thinks. The harness does. Together, they’re an agent.
